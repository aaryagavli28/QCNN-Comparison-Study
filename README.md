# QCNN Comparison Study

## Models Compared

- Single Encoding QCNN
- Multi Encoding QCNN
- Multi Noisy QCNN
- Inception QCNN

## Dataset

- MNIST 179

## Final Results

| Model | Validation Accuracy |
|---------|---------:|
| Inception | 92.08% |
| Multi Encoding | 83.33% |
| Multi Noisy | 82.92% |
| Single Encoding | 79.58% |
